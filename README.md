## 🌱 عن المشروع

**اتزان (Itizan)** منصة ويب عربية تساعد الأطفال واليافعين على بناء عادات رقمية أكثر توازنًا، من خلال تحديات يومية بسيطة تشجعهم على استبدال جزء من وقت الشاشة بأنشطة واقعية.

بدلًا من الحجب والمراقبة، يعتمد اتزان على التغيير التدريجي والتحفيز الإيجابي عبر شجرة افتراضية تنمو مع الالتزام.

جاءت الفكرة استجابةً لتحدّي الإدمان الرقمي في جائزة نورة الملاحي للابتكار الاجتماعي التقني.

## ✨ المزايا

* اختيار هدف إلى ثلاثة أهداف شخصية.
* تحديات يومية من مكتبة أنشطة واقعية.
* شجرة افتراضية تتطور مع أيام الالتزام.
* متابعة النقاط وساعات الاستخدام والتقدم الأسبوعي.
* واجهة عربية متجاوبة تدعم اتجاه RTL.
* حسابات مستقلة مع حماية كلمات المرور وبيانات المستخدمين.

## 🚀 التشغيل محليًا

يتطلب Python 3.10 أو أحدث.

```bash
git clone https://github.com/ShahadAlmalki-cs/Itizan.git
cd Itizan

python -m venv .venv
```

تفعيل البيئة الافتراضية على Windows:

```powershell
.\.venv\Scripts\Activate.ps1
```

تثبيت الاعتماديات وتشغيل التطبيق:

```bash
python -m pip install -r requirements.txt
python app.py
```

افتح `http://127.0.0.1:5000` في المتصفح.

لتشغيل الاختبارات:

```bash
python -m unittest discover tests -v
```
